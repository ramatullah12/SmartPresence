# SmartPresence — Sistem Absensi Digital & Geolocation

Aplikasi web SaaS modern untuk manajemen presensi digital pegawai dan mahasiswa berbasis **Geolocation GPS** dan **Dynamic QR Code**.

## Arsitektur Direktori
- `frontend/` — Aplikasi Frontend berbasis **React.js (Vite)**, **Tailwind CSS**, **Lucide React**, **React Router DOM**, dan **Axios**.
- `backend/` — Aplikasi Backend REST API berbasis **Laravel** & **Laravel Sanctum** (MySQL).
